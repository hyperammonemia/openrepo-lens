这些指标如何计算？

Issue 与 Pull Request 按 API 的 pull_request 字段区分。30 / 90 天窗口从采集起始时刻向前计算，筛选记录的创建时间；状态是实际采集时读到的状态。

样本已关闭占比 = 当前窗口中已关闭 Issue 数 ÷ Issue 数。已关闭耗时中位数仅统计有效的已关闭 Issue，从创建到最后关闭的天数；它受已关闭样本选择影响，不能等同于整体处理速度或首次响应时间。

未关闭年龄为采集起始时间与创建时间的差值。关闭并不一定代表问题修复，PR 也不参与 Issue 关闭指标。缺失值显示「—」，不作为零处理。
